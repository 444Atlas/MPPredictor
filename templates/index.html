01 / MOTEUR D'INFÉRENCE & PRÉDICTION

Modélisation probabiliste des confrontations internationales.

Évaluation quantitative des probabilités de match pour la Coupe du Monde 2026. L'architecture associe un réseau de neurones multicouches (PyTorch) entraîné sur dix années de résultats officiels et un modèle bivarié de Poisson pour la calibration dynamique des scores exacts.

  • Échantillon 8 281 matchs internationaux traités (2016–2026).
  • Descripteurs 29 variables composites (ELO dynamique, notes FIFA, ratios d'attaque/défense, forme récente).
  • Simulation 10 000 tirages de Monte Carlo par confrontation, ajustés par le ratio de force neuronal.

03 / SPÉCIFICATION TECHNIQUE

Intégration via l'API REST

Point de terminaison JSON direct pour interroger le modèle depuis n'importe quel client HTTP.

Requête HTTP (POST /predict)
curl -X POST "http://localhost:8000/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "team_home": "France",
       "team_away": "Brazil",
       "is_neutral": 1.0,
       "is_world_cup": 1.0
     }'
Réponse d'inférence (JSON)
{
  "match": "France vs Brazil",
  "proba_victoire_home": 59.92,
  "proba_nul_ou_defaite": 40.08,
  "score_predit": "1 - 1",
  "home_goals": 1,
  "away_goals": 1
}
